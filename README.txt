مصاريف الصيانة - نسخة الآيفون (PWA مع أوفلاين)
================================================
الملفات: index.html · sw.js · manifest.webmanifest · icon-192.png · icon-512.png · apple-touch-icon.png
كلها لازم تنرفع سوية بنفس المجلد.

الاستضافة (اختر واحدة، كلها مجانية):

أ) Netlify Drop (الأسهل، بدون كود)
   1. افتح app.netlify.com/drop
   2. اسحب المجلد كامل (مجلد الملفات الستة) على الصفحة.
   3. يعطيك رابط https://xxxx.netlify.app . سجّل حساب حتى ما ينحذف الموقع بعد ساعة.
   4. من الإعدادات تكدر تغيّر الاسم إلى شي قصير مثل masarif.netlify.app

ب) GitHub Pages
   1. أنشئ مستودع جديد (Public) وارفع الملفات الستة.
   2. Settings ثم Pages ثم Source: Deploy from a branch ثم main ثم / (root) ثم Save.
   3. الرابط: https://اسمك.github.io/اسم-المستودع/

التثبيت على الآيفون (لكل موظف):
   1. افتح الرابط بـ Safari (مو Chrome).
   2. زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».
   3. افتح التطبيق من الأيقونة الجديدة، وسجّل دخولك بالكود (التسجيل داخل Safari ما ينتقل للأيقونة).
   4. افتحه مرة واحدة وأنت متصل بالإنترنت حتى يحفظ نفسه وبياناته. بعدها يشتغل بدون نت.

التحديث: إذا غيّرت أي ملف، ارفعه فوق القديم. التطبيق ياخذ التحديث بعد فتحه مرتين.
